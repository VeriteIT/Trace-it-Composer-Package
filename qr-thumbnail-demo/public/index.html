Right-click any article photo and choose “Save image as…” — the downloaded file includes a scannable Trace-It code.

·

How this works

Everything below happens automatically on page load. There is no button and no user action — one script tag is the whole integration.

  1. Script self-initialises on DOM ready and finds the article thumbnails.
  2. Server calls POST /api/v1/qr on Trace-It and gets back a PNG (base64 data URI).
  3. Browser loads the article photo through a same-origin path so the canvas stays untainted.
  4. Photo and QR are drawn to a <canvas> at the photo's native resolution.
  5. Canvas is exported to a Blob, and the original <img src> is pointed at it.
  6. Native “Save image as…” now writes the composite — the QR is the image.

Why not intercept the save?

“Save image as…” is a native browser menu. No DOM event fires and it cannot be hooked from JavaScript. Baking the QR into the displayed image is the only approach that survives a native save — and it works in every browser.

Island Chronicle is a fictional publication built to demonstrate Trace-It QR embedding.
